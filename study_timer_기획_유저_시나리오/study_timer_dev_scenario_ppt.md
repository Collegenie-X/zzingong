## 슬라이드 5: 웹 앱의 구조 - 식당 비유

**프론트엔드 = 홀 (손님이 보는 곳)**
**백엔드 = 주방 (요리하는 곳)**

| 역할 | 비유 | 기술 |
|------|------|------|
| 프론트엔드 | 홀 - 메뉴판, 테이블, 인테리어 | HTML, CSS, JavaScript |
| 백엔드 | 주방 - 재료 보관, 요리, 레시피 | Python Flask |
| API | 홀 직원 - 주문서를 주방에 전달 | fetch, JSON |
| 데이터 | 냉장고 - 재료와 장부 보관 | JSON, CSV 파일 |

손님(사용자)이 주문(클릭)하면 → 홀 직원(JavaScript)이 주방(Flask)에 전달 → 주방이 냉장고(JSON)에서 꺼내 요리(처리) → 결과를 다시 손님에게 서빙

## 슬라이드 11: Phase 1 - Flask 서버 (주방 만들기)

**Flask = Python으로 만든 미니 주방 세트**

| 주문 (URL) | 주방장이 하는 일 | 비유 |
|------------|-----------------|------|
| `/` | 메인 페이지 표시 | 메뉴판 보여주기 |
| `/timer` | 타이머 페이지 표시 | 공부방 안내 |
| `/api/subjects` | 과목 목록 보내기 | 냉장고에서 재료 목록 꺼내기 |
| `/api/subjects/add` | 새 과목 저장 | 새 재료 냉장고에 넣기 |
| `/api/sessions/save` | 공부 기록 저장 | 오늘 매출 장부에 적기 |

**서버 실행:** `python app.py` → `http://localhost:5000` 접속

- `@app.route("/")` = 건물 안내판 ("1층 = 로비")
- `render_template()` = 종이에 인쇄해서 손님에게 건네기

## 슬라이드 14: Phase 1 - JavaScript 타이머 (전기 배선)

## 슬라이드 20: Phase 2 - AI 코멘트 (자동 생활기록부)

**담임선생님이 매일 써주는 생활기록부 코멘트 — 자동 버전!**

IF-ELSE 규칙으로 만든 **코멘트 자판기:**

| # | 항목 | 규칙 예시 |
|:-:|------|----------|
| 1 | 잘한 점 | 순공률 80%↑ → "집중력 최고!" / 어제보다↑ → "발전 중!" |
| 2 | 개선할 점 | 0분 과목 → "이 과목을 안 했어요" |
| 3 | 딴짓 분석 | 핸드폰 30분↑ → "다른 방에 두세요" |
| 4 | 추천 | 순공률↓ → "25분 집중 + 5분 휴식" (뽀모도로) |
| 5 | 다음 목표 | 미달 → "내일은 10분 더 해볼까요?" |

진짜 AI가 아니라, **점수에 따라 미리 정해진 문장을 골라주는 자판기!**

**채점 과정:**
1. 일기장(세션 JSON)을 꺼낸다
2. 모든 교시의 점수를 합산한다
3. 과목별 달성률을 계산한다
4. 성적표(JSON)를 만들어서 보내준다

## 슬라이드 26: Phase 3 - 자리 이탈 감지 (출석 체크)

**얼굴이 안 보이면 = 자리를 비웠다!**

```
매 0.1초마다:
  얼굴 보임? → O → 출석!
  얼굴 안 보임? → 1초 이상 연속 → X → 자리 이탈!
```

**왜 1초를 기다리나? 한 번 안 보인다고 결석은 억울!**

| 상황 | 시간 | 판정 |
|------|:----:|------|
| 교재 보려고 고개 숙임 | 0.3초 | 무시 (공부 중!) |
| 재채기 | 0.5초 | 무시 (생리 현상) |
| 화장실 감 | 3초+ | 자리 이탈! |
| 간식 가지러 감 | 10초+ | 확실히 자리 이탈! |

이것이 **디바운싱** = **엘리베이터 버튼**: 연타해도 한 번만 인식!

## 슬라이드 27: Phase 3 - 졸음 감지 (EAR)

**EAR = 눈의 세로 ÷ 가로 = 만두 납작함 측정기**

눈이 열림 (통통한 만두) → EAR = 0.30 → 깨어있다!
눈이 감김 (납작한 만두) → EAR = 0.10 → 졸고 있다!

**판정 기준:** EAR < 0.20이 **1.5초 이상** 지속되면 → 졸음!

| 상황 | EAR | 시간 | 판정 |
|------|:---:|:----:|------|
| 일반 눈 깜빡임 | 0.10 | 0.2초 | 무시 (정상) |
| 졸음 | 0.15 | 1.5초+ | 졸음 감지! 😴 |
| 활짝 뜬 눈 | 0.30 | - | 깨어있음 🟢 |

> 피타고라스 정리로 두 점 사이 거리를 계산합니다!
> 중학교 수학이 여기서 쓰여요!
