# AI 공부 매니저 - 나의 시간은 어디로 갔을까?

## 프로젝트 소개

**"나는 진짜 몇 시간 공부했을까?"**

컴퓨터 웹캠이 나를 지켜보면서, 진짜 공부한 시간과 딴짓한 시간을 자동으로 분류해주는 AI 학습 관리 시스템

- 📖 순공 시간: 진짜 집중해서 공부한 시간
- 📱 딴짓 시간: 핸드폰, 멍때림, 졸음 등 공부 외 활동
- 📊 통계: 1일 / 1주일 / 1달 단위 리포트 + AI 코멘트

**기술**: Python Flask + HTML/JavaScript + MediaPipe + YOLO Tiny

**데이터 저장**: JSON / CSV 파일 (DB 없이 간단하게!)

![AI가 공부하는 학생을 모니터링하는 미래적인 일러스트](image: friendly AI assistant monitoring a middle school student studying at desk with webcam, colorful and modern illustration style)

## 우리가 겪는 문제

중학생이라면 누구나 공감하는 상황:

**"분명 3시간 앉아있었는데, 뭘 했는지 모르겠다"**

| 내가 생각하는 나 | 실제 나 |
|:---:|:---:|
| "3시간 공부했다" | 실제 집중은 1시간 반 |
| "핸드폰 잠깐 봤다" | 합치면 40분 넘게 봄 |
| "쉬는 시간은 10분이었다" | 사실 30분 쉬었다 |
| "수학 많이 했다" | 영어는 20분도 안 했다 |

**문제의 핵심**: 내가 시간을 어디에 쓰는지 **정확히 모른다**

시간을 어디에 쓰는지 알아야, 더 잘 쓸 수 있습니다!

![학생이 책상에 앉아서 핸드폰 보다가 깜짝 놀라며 시계를 보는 만화 스타일 그림](image: comic style illustration of student sitting at desk looking at phone then shocked looking at clock realizing time has passed)

## 솔루션 - AI 공부 매니저

컴퓨터 앞에 앉으면, 웹캠이 자동으로 나의 행동을 분류합니다:

**시간을 2가지로 분류:**

| 분류 | 색상 | 포함되는 행동 |
|------|:----:|--------------|
| **📖 순공 시간** | 🟢 초록 | 교재 집중, 필기, 화면 집중 학습 |
| **📱 딴짓 시간** | 🔴 빨강 | 핸드폰, 멍때림, 졸음, 잡담, 자리 이탈 |

**딴짓 시간도 세분화해서 기록:**

| 딴짓 종류 | 아이콘 | 어떻게 감지? |
|-----------|:------:|-------------|
| 핸드폰 사용 | 📱 | YOLO가 핸드폰 객체 감지 |
| 졸음/눈 감김 | 😴 | 눈 감김 비율(EAR) 측정 |
| 멍때림/고개 돌림 | 😶 | 고개 방향이 오래 벗어남 |
| 자리 비움 | 🚶 | 얼굴 미검출 |
| 기타 | ❓ | 위에 해당 안 되는 비집중 |

**핵심**: 순공 시간뿐 아니라 **"딴짓에 얼마나 썼는지"**도 알려줍니다!

## 핵심 기능 요약

AI 공부 매니저의 4가지 핵심 기능:

**기능 1: 자동 행동 분류** 🤖
- 웹캠이 나를 보면서 집중/딴짓을 자동 판별
- 순공 시간 vs 딴짓 시간을 실시간 분류

**기능 2: 딴짓 세분화** 📱
- 핸드폰 몇 분, 졸음 몇 분, 멍때림 몇 분 각각 기록
- "시간이 어디로 갔는지" 정확하게 파악

**기능 3: 실시간 알림** ⚡
- 고개 오래 돌리면 "집중해 주세요!"
- 핸드폰 5분 넘으면 "핸드폰 내려놓을까요?"
- 50분 집중하면 "잘하고 있어요! 쉬는 시간!"

**기능 4: 통계 + 코멘트** 📊
- 1일 / 1주일 / 1달 통계 자동 생성
- "이번 주 수학 시간이 부족해요" 같은 고정 코멘트 제공

## 시간 분류 체계 - 2가지 시간

모든 시간을 **순공 시간**과 **딴짓 시간** 2가지로 나눕니다:

**순공 시간 (초록색) 🟢**

| 행동 | 판별 방법 |
|------|-----------|
| 교재/노트 집중 | 고개가 아래(교재) 방향 + 안정적 |
| 화면 집중 학습 | 정면 응시 + 눈 초점 안정 |
| 필기 중 | 고개 아래 + 미세한 움직임 |

**딴짓 시간 (빨간색) 🔴**

| 딴짓 종류 | 아이콘 | 판별 방법 | 기록 내용 |
|-----------|:------:|-----------|-----------|
| 핸드폰 사용 | 📱 | YOLO 핸드폰 감지 | 몇 분, 몇 회 |
| 졸음 | 😴 | 눈 감김 1.5초 이상 | 몇 분, 몇 회 |
| 멍때림/고개 돌림 | 😶 | 고개 방향 30°+ 이탈 2초+ | 몇 분, 몇 회 |
| 자리 비움 | 🚶 | 얼굴 미검출 1초+ | 몇 분, 몇 회 |
| 기타 비집중 | ❓ | 위에 해당 안 됨 | 몇 분 |

**일일 시간 사용 파이 차트 예시:**

| 구분 | 시간 | 비율 |
|------|------|------|
| 🟢 순공 시간 | 1시간 52분 | 62% |
| 📱 핸드폰 | 28분 | 16% |
| 😶 멍때림 | 15분 | 8% |
| 🚶 자리 비움 | 12분 | 7% |
| 😴 졸음 | 8분 | 4% |
| ❓ 기타 | 5분 | 3% |

## 실시간 알림 (체크 & 응원)

공부하는 동안 웹캠이 체크하고, 상황에 맞는 메시지를 보여줍니다:

**경고 알림 ⚠️**

| 상황 | 조건 | 화면 메시지 |
|------|------|-------------|
| 고개 오래 돌림 | 고개 30°+ 이탈 10초 이상 | 💬 "집중해 주세요! 다시 교재를 봐볼까요?" |
| 핸드폰 사용 | 핸드폰 감지 후 3분 경과 | 💬 "핸드폰 3분째예요. 내려놓을까요?" |
| 핸드폰 장시간 | 핸드폰 감지 후 5분 경과 | 💬 "핸드폰 5분! 지금 내려놓으면 아직 늦지 않았어요!" |
| 핸드폰 빈번 | 10분 내 3회 이상 | 💬 "핸드폰을 자꾸 보고 있어요. 무음 모드 어때요?" |
| 졸음 감지 | 눈 감김 1.5초 | 💬 "졸리면 5분만 스트레칭 하고 와요!" + 🔔 알림음 |
| 자리 10분 이상 | 얼굴 미검출 10분 | 💬 "10분째 자리를 비웠어요. 돌아와서 마저 해볼까요?" |

**응원 알림 🎉**

| 상황 | 조건 | 화면 메시지 |
|------|------|-------------|
| 25분 연속 집중 | 순공 25분 달성 | 💬 "25분 집중 완료! 대단해요! 5분 쉬어도 돼요 😊" |
| 50분 연속 집중 | 순공 50분 달성 | 💬 "50분이나 집중했어요!! 10분 푹 쉬고 오세요 🏆" |
| 과목 목표 달성 | 수학 1시간 완료 | 💬 "수학 오늘 목표 달성! 👏 다른 과목도 도전!" |
| 전일 목표 달성 | 전체 3시간 완료 | 💬 "오늘 목표 완료!! 정말 잘했어요! 🎊🎊🎊" |
| 연속 출석 | 3일 연속 사용 | 💬 "3일 연속 공부! 꾸준함이 실력이에요 💪" |

## 유저 시나리오 1 - 첫 사용: 과목 설정

서준이가 처음 AI 공부 매니저를 사용하는 과정:

**Step 1: 접속**
- 브라우저에서 AI 공부 매니저 열기 (설치 없음!)

**Step 2: 과목 등록**

| 과목 | 일일 목표 | 주간 목표 |
|------|-----------|-----------|
| 수학 | 1시간 | 5시간 |
| 영어 | 40분 | 3시간 |
| 국어 | 30분 | 2시간 30분 |
| 과학 | 30분 | 2시간 30분 |
| 사회 | 20분 | 1시간 30분 |
| **합계** | **3시간** | **14시간 30분** |

**Step 3: 웹캠 연결**
- "카메라 접근을 허용하시겠습니까?" → 허용
- 내 얼굴이 화면에 보이면 준비 완료!

**Step 4: 공부 시작!**
- 과목 선택 → "공부 시작" 클릭 → 끝!

**포인트**: 순공 타이머와 딴짓 타이머가 **동시에 보임** → 내 시간이 어디로 가는지 실시간 체감

수학 공부를 끝내고 "종료"를 누르면 나오는 리포트:

**세션 요약 - 수학 (16:00 ~ 17:15)**

| 항목 | 시간 | 비율 |
|------|------|:----:|
| ⏱️ 총 경과 시간 | 1시간 15분 | 100% |
| 🟢 **순공 시간** | **48분** | **64%** |
| 🔴 딴짓 시간 합계 | 27분 | 36% |

**딴짓 상세 분석:**

| 딴짓 종류 | 시간 | 횟수 | 평균 1회 |

## 알고리즘 1 - 졸음 감지 (EAR)

눈이 감겨있는 비율로 졸음을 판별합니다:

**EAR (Eye Aspect Ratio) = 눈의 세로 ÷ 가로**

| 상태 | EAR 값 | 의미 |
|------|:------:|------|
| 눈 크게 뜸 | 0.30 | 초롱초롱 |
| 눈 보통 | 0.25 | 정상 |
| 눈 가늘어짐 | 0.20 | 피곤? |
| **눈 감김 (1.5초+)** | **< 0.20** | **😴 졸음!** |
| 눈 깜빡임 (0.3초 미만) | < 0.20 | 정상 깜빡임 (무시) |

**판별 로직:**
1. 매 프레임마다 양쪽 눈의 EAR 계산
2. 평균 EAR < 0.20 이면 → 눈감김 카운터 +1
3. 카운터가 15프레임(1.5초) 연속이면 → **졸음 판정!**
4. 💬 "졸리면 5분만 스트레칭 하고 와요!" + 🔔 알림음
5. 카운터 리셋

**왜 1.5초?**: 정상적인 눈 깜빡임은 0.1~0.4초. 1.5초 이상 감기면 졸음.

## 알고리즘 2 - 고개 방향 (집중도)

고개가 어디를 향하는지로 집중 여부를 판별합니다:

**3가지 각도 측정:**

| 각도 | 동작 | 집중 범위 | 비집중 |
|------|------|:---------:|--------|
| **Yaw** | 좌우로 고개 돌림 | -30° ~ +30° | 옆을 봄 |
| **Pitch** | 위아래로 고개 숙임/젖힘 | -35° ~ +25° | 너무 숙이거나 젖힘 |
| **Roll** | 고개 기울임 | -20° ~ +20° | 참고만 함 |

**실시간 체크 알림:**

| 상황 | 시간 | 알림 |
|------|------|------|
| 고개 살짝 돌림 (2초 미만) | 무시 | - (잠깐 보는 건 OK) |
| 고개 돌림 2초~10초 | 비집중 기록 시작 | (조용히 딴짓 시간에 기록) |
| **고개 돌림 10초 이상** | 비집중 + 알림 | 💬 **"집중해 주세요! 다시 교재를 봐볼까요?"** |
| 고개 돌림 30초 이상 | 강한 알림 | 💬 **"30초째 다른 곳을 보고 있어요!"** + 🔔 |
| 고개 돌림 1분 이상 | 최종 알림 | 💬 **"혹시 쉬는 시간인가요? 일시정지를 눌러주세요"** |

**디바운싱**: 잠깐 고개 돌리는 건 허용. **2초 이상** 지속해야 비집중으로 판정.

## 알고리즘 3 - 핸드폰 감지 (YOLO)

| 사용 시간 | 알림 |
|-----------|------|
| 0~2초 | (무시 - 잠깐 시계 확인 등) |

**왜 2초 디바운싱?**: 시간 확인하려고 핸드폰을 잠깐 보는 건 딴짓이 아님

## 개발 로드맵 - 4단계

단계별로 기능을 추가합니다:

| Phase | 이름 | 기간 | 핵심 기능 |
|:-----:|------|:----:|-----------|
| **1** | 기본 타이머 | 2주 | 과목별 수동 타이머, JSON 저장 |
| **2** | 대시보드 | 4주 | 일/주/월 통계, 코멘트, CSV 통계 |
| **3** | MediaPipe | 3주 | 자동 순공/딴짓 분류, 실시간 알림 |
| **4** | YOLO | 5주 | 핸드폰 감지, 딴짓 세분화 |

**Phase 1 (기본 타이머):**
- 과목 등록 + 목표 설정
- 시작/정지 수동 타이머
- 세션 기록을 JSON 파일에 저장

**Phase 2 (대시보드):**
- 일간/주간/월간 통계 화면
- 5가지 고정 코멘트 자동 생성
- CSV 파일로 통계 내보내기

**Phase 3 (MediaPipe):**
- 웹캠으로 졸음/고개 방향/자리 이탈 감지
- 순공 vs 딴짓 자동 분류
- 실시간 알림 ("집중해 주세요!")

**Phase 4 (YOLO):**
- 핸드폰 객체 감지
- 딴짓 5종 세분화 (핸드폰/졸음/멍때림/자리비움/기타)
- 행동별 시간 파이 차트

## Phase 3 - MediaPipe 자동 감지

웹캠을 켜면 AI가 자동으로 집중/딴짓을 분류:

**이 단계에서 바뀌는 것:**

| 항목 | Phase 2 (수동) | Phase 3 (자동) |
|------|:--------------:|:--------------:|
| 타이머 | 내가 직접 시작/정지 | 집중하면 자동 시작, 딴짓하면 자동 정지 |
| 딴짓 기록 | 없음 (수동이니까) | **자동으로 딴짓 시간 기록** |
| 졸음 | 모름 | **자동 감지 + 알림** |
| 알림 | 없음 | **"집중해 주세요!" 실시간 알림** |
| 순공 의미 | 시작~정지 = 순공 (부정확) | **진짜 집중한 시간만 = 순공** |

**실시간 알림 작동:**
- 고개 10초 이상 돌림 → 💬 "집중해 주세요!"
- 핸드폰 3분 → 💬 "핸드폰 내려놓을까요?"
- 눈 1.5초 감김 → 💬 "졸리면 스트레칭!" + 🔔
- 25분 연속 집중 → 💬 "25분 집중! 대단해요!" 🎉

**이 단계부터 진짜 AI 공부 매니저!**
